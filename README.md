# 酷安 Web —— 网页版酷安

在浏览器里刷酷安的本地 Web 应用。

- **后端**（Node.js + Express）：每个请求实时生成酷安 `X-App-Token`（v3 签名算法），代理酷安接口与图床，解决签名和图片防盗链问题
- **前端**（原生 HTML/CSS/JS）：三栏布局，左侧导航、中间内容流、右侧动态详情

## 功能说明

**内容浏览**

- 六个栏目：首页（快讯）、头条（热榜）、话题、酷图、数码、应用
- 列表无限滚动，动态详情与评论在右栏展示
- 评论自动加载完整列表；仅当需要滑块验证时才显示「查看评论」入口
- 动态与评论正文支持酷安表情（`[流泪]` 等自动转成表情图）
- 图片点击可灯箱预览，支持左右切换
- 动图在列表 / 详情中显示静态首帧和 GIF 标记，点击后才在灯箱播放

**话题**

- 热门话题列表、话题搜索
- 关注话题：登录后同步到账号，未登录时保存在本机
- 话题动态支持「最新 / 热门」排序

**酷图 / 数码 / 应用**

- 酷图：按分类或标签浏览、搜索
- 数码：分类切换、热度 / 最新排序、产品讨论
- 应用：排行榜、搜索、应用详情弹窗、评论
- 关注应用：登录后同步到账号，未登录时保存在本机

**账号**

- 左下角显示头像、昵称
- 点击头像可退出登录（不删除账号数据），并从「最近登录」一键切回
- 支持「官网登录后粘贴 Cookie 自动识别」，也支持手动填写 uid / username / token
- 凭证只保存在本机 `data/account.json`，最近登录记录在 `data/accounts.json`
- 未登录时关注的话题 / 应用保存在 `data/follows.json`

**外观**

- 每次进入随机一套彩色主题，侧边栏「设置」里可手动切换
- 内置 6 套配色 + 暗黑主题

## 项目结构

```
server.js            后端入口：token 生成、接口代理、图床代理、静态托管
lib/
  token.js           X-App-Token v3/v2 签名算法
  token_v3_data.*    v3 协议查找数据
public/
  index.html         页面结构
  style.css          样式与主题变量
  app.js             前端逻辑（列表、详情、评论、登录、主题等）
  emotions/          酷安表情图片
  logo.ico           站点图标
data/                本地数据（account.json 当前账号、accounts.json 最近登录、
                     guest.json 游客设备、follows.json 本地关注、
                     captcha.json 验证码凭证）
log/                 诊断日志（仅错误与关键事件，保留 3 天）
start.bat            本地启动脚本
package.json         依赖与启动命令
.gitignore           Git 忽略规则（排除 data/、log/ 等本地数据）
```

> `data/`、`log/` 由程序自动创建，已在 `.gitignore` 中排除。

## 使用方法

```bash
npm install
npm start
```

然后打开 <http://localhost:9002>。

需要 Node.js 18+（使用内置 fetch）。

首次使用可在左下角「账号设置」里配置账号：推荐先点「打开酷安官网登录页」完成登录，再把 `account.coolapk.com` 的 Cookie 整段粘贴回来自动识别；也可以手动填写 uid / username / token。配置只保存在本机，不会上传。

## 说明

- 数据仅保存在本地 `data/` 与 `log/` 目录，不随代码提交。
- 页面只显示友好错误；上游故障、登录失败等详细上下文写入 `log/`（保留 3 天），普通请求不记录。
- 基于酷安非官方接口，仅供学习研究，请勿商用；酷安改版可能导致部分功能失效。
